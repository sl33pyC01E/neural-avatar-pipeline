# Legacy EMAGE diffusion lab

This folder contains the older combined EMAGE, Kimodo, Kokoro, and VNyan retargeting lab. It is retained for reference and is not used by Motion Drive.

Run `start_retargetting_lab.bat` to launch it at <http://127.0.0.1:8791/>. The server still uses dependencies from the repository's top-level `node_modules` folder and writes legacy generated data under this folder's ignored `runs/` directory.
